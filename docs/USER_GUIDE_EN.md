# Tsebisa – Short User Guide (English)

## For Community Members

### What is Tsebisa?
Tsebisa is a simple way to tell the local office about problems with water, roads, refuse collection, street lights and other services. You get a reference number so you can follow up.

### How to report a problem
1. Open the Tsebisa page (or dial the USSD code when it is available).
2. Choose **English**.
3. Choose the type of problem.
4. Write a short description (example: “Water pump not working since Monday”).
5. Write the location or village name.
6. Enter your phone number.
7. Submit. You will see a reference number such as **TSE-7K2M**. Keep it.

### Important
- Reporting does **not** mean the problem will be fixed immediately.
- It helps the responsible office see the problem.
- You can use a shared phone. The pilot records your number with the report, but does not send SMS messages.

---

## For the Partner Organisation

1. Open the **Dashboard**.
2. You will see a list of reports with reference numbers, category, location and status.
3. Click a reference number to see full details.
4. Change the status:
   - **Received** – we have seen the report
   - **In progress** – someone is working on it
   - **Closed** – the issue has been dealt with (or closed for another reason)
5. Use the information to prioritise work and to show the community that their reports are being looked at.

### Good practice
- Try to update status within a few days.
- If possible, tell the community (in meetings or on a notice board) that reports are being received.
- Do not promise what you cannot deliver.
