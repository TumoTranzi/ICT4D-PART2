Tsebisa

Community Service Delivery Reporting for Lesotho. Report problems with water, roads, refuse and more — simply, in Sesotho, from any phone.

This pilot prototype simulates a USSD/SMS reporting channel designed for feature phones and low-connectivity areas. Citizens get an immediate reference number; the partner organisation sees reports on a simple dashboard.

Start a Report (Citizen) Partner Dashboard User Guide (EN / ST)

How it works (pilot)

*123# 1. Khetha puo / Choose language 2. Khetha bothata / Choose problem type 3. Hlalosa + sebaka / Describe + location 4. Fumana nomoro ea reference → Confirmation shown on screen

In a full deployment this flow runs over real USSD. For the student pilot we use a mobile-friendly web simulation that follows the same simple steps.
