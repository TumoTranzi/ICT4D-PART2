Tsebisa

Community Service Delivery Reporting for Lesotho. Report problems with water, roads, refuse and more — simply, in Sesotho or English, on the website.

This pilot provides a web reporting form and a browser-based USSD phone simulator. Reports receive a reference number; Ministers and the Prime Minister can review them and reply in a shared conversation. The browser USSD simulator is available; real SMS requires a configured gateway account.

Start a Report (Citizen) Minister Dashboard Track / Reply to a Report Citizen Guide (EN / ST)

How it works (pilot)

*123# 1. Khetha puo / Choose language 2. Khetha bothata / Choose problem type 3. Hlalosa + sebaka / Describe + location 4. Fumana nomoro ea reference → Confirmation shown on screen

In a full deployment this flow runs over real USSD. For the student pilot we use a mobile-friendly web simulation that follows the same simple steps.
