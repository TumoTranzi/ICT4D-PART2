How to use the simulator

  1. Press *123# on the keypad to open the Tsebisa menu.
  2. Choose 1 for Sesotho or 2 for English.
  3. Follow the menu choices to select the service problem.
  4. For location, description and phone number, type into the response box or use the number keys.
  5. Press OK to send each response.
  6. Confirm the report to save it. A reference number will appear on the phone screen.

Note: This is a browser-based simulation of a USSD session. It uses the existing Flask /api/ussd endpoint and does not require an actual shortcode or charge mobile airtime.
