Citizen Guide / Tataiso ea Moahi

Short guide for citizens and ministers.

For Citizens (English)

  1. Go to the Tsebisa reporting page (or dial the USSD code in a full deployment).
  2. Choose your language (Sesotho or English).
  3. Select the type of problem (water, roads, refuse, street lights, or other).
  4. Write a short description and the location/village.
  5. Enter your phone number. It is used to verify the report conversation and, when an SMS gateway is configured, receive a reference confirmation.
  6. Submit. You will receive a reference number (e.g. TSE-7K2M). Keep it.
  7. Use Track / Reply, your reference and the same phone number to read and reply to messages from staff.

Important: Reporting does not guarantee immediate repair. It makes the problem visible to the responsible office.

Bakeng sa Baahi (Sesotho)

  1. E-ea leqepheng la Tsebisa (kapa o letse khoutu ea USSD ha e se e le teng).
  2. Khetha puo (Sesotho kapa Senyesemane).
  3. Khetha mofuta oa bothata (metsi, litsela, lithoele, mabone, kapa tse ling).
  4. Ngola tlhaloso e khutšoane le sebaka/motse.
  5. Kenya nomoro ea hau ea mohala. E thusa ho netefatsa puisano ya tlaleho; ha SMS gateway e hokantswe, o ka fumana tiisetso ya nomoro ya referense.
  6. Romela. U tla fumana nomoro ea reference (mohlala TSE-7K2M). E boloke.
  7. Sebelisa Track / Reply, nomoro ea reference le nomoro e tšoanang ea mohala ho bona le ho araba basebetsi.

Hlokomela: Ho tlaleha ha ho tiise hore bothata bo tla lokisoa hang-hang. E thusa hore ofisi e e ikarabellang e bone bothata.

For Ministers

  • Open the Dashboard to see all incoming reports.
  • Click a reference number to see full details.
  • Update the status: Received → In progress → Closed.
  • Open the report conversation to reply to citizens. Status changes appear as updates in that conversation; SMS notifications work only after a gateway account is configured.
  • Use the reports to prioritise work and to show the community that their voice is heard.

Technical Notes (for handover)

  • This pilot uses a web simulation of the USSD flow + SQLite database.
  • To connect a real USSD/SMS gateway (e.g. Africa’s Talking), use the /api/ussd endpoint and adapt the session handling.
  • Source code is kept simple so a local technician or student can maintain it.
  • Data is stored locally in tsebisa.db. Back it up regularly.
